# Lightweight React Template for KAVIA

This project now includes a modern, Ocean Professional themed Calculator application.

## Keyboard Shortcuts

- Digits: 0-9
- Decimal: .
- Operators: +, -, *, /
- Percentage: %
- Toggle Sign: not mapped to keyboard, use button +/−
- Evaluate: Enter or =
- Clear: Esc
- Delete: Backspace

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner.

### `npm run build`

Builds the app for production to the `build` folder.
